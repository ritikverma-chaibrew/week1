Setup guide

Connect a Gemma model so your coach can reply and give feedback. Choose the option that fits you.

Option 1

Use your own API key (hosted)

Best when you are using the deployed site. Your key is only used to call the model for your session.

  1. Get a key. Open Google AI Studio, sign in and choose Create API key. Copy it.
  2. Open the key box. Go to Practice and expand Use your own Gemma API key.
  3. Paste and save. Paste the key and press Use key. The warning banner at the top should disappear.
  4. Start practicing. Pick a mode and press Start practice.
  • The key is kept in server memory for about an hour and is never stored or shown again. Paste it again if it expires.
  • Use Remove key to clear it at any time.
  • Never share your key or paste it into other people's sites.
Option 2

Run a local model with LM Studio

Free and private, but it only works when you run this app on your own computer.

  1. Download a model. In LM Studio, search for gemma 3 4b and download the instruct version (Q4_K_M).
  2. Start the server. Open the Developer tab, load the model and switch the server on. The default address is http://localhost:1234.
  3. Find the model name. Open http://localhost:1234/v1/models and copy the id of your model.
  4. Fill in your .env file (copy .env.example if you don't have one) with these three values, then restart the app:
API URL    http://localhost:1234/v1/chat/completions
API key    lm-studio
Model      google/gemma-3-4b
  • LM Studio ignores the key, so any placeholder works.
  • The three settings are the first lines of .env.example: the URL, the key and the model.
  • Local models run slowly on a CPU. Add a longer AI_TIMEOUT_SECONDS (for example 120) if requests time out.
Models

Choosing a model

The model name is set in your .env file and must exist on the endpoint you use. On the hosted site the model is chosen by the site owner.

Where it runsGood choiceNotes
Hosted (Google)gemma-4-31b-itMost accurate feedback. Needs an API key.
Local, 16 GB RAM, no GPUGemma 3 4BBest balance of speed and valid JSON feedback.
Local, strong GPUGemma 3 12B or largerBetter corrections and explanations.
Local, any machineGemma 3 1B or smallerOften returns broken feedback. Avoid.

Troubleshooting

The banner says the provider is not configured correctly
No key is set yet. Paste your key (Option 1) or fill in the URL, key and model in .env (Option 2).
"Coach feedback" says feedback was not available
The model did not return valid JSON. Use a larger model.
Requests time out
The model is too slow for the timeout. Use a smaller model or add a longer AI_TIMEOUT_SECONDS in .env.
Local model does not work on the deployed site
A hosted server cannot reach your computer. Use Option 1 there.
